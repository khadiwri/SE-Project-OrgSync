OrgSync
Description: An event calendar application used by students, campus organizations, and school faculty. This calendar will serve as an event hub of all occurences happening on campus. Students can discover and save events of interest or follow and join an organization all together. Office of Student Activites will be able to create and modify events listed by student organizations who will share some of the admin properties.
